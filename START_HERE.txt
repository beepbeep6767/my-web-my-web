อัปเดตระบบโรงเรียน 9 ตุลาคม 2026:
อ่าน SCHOOL_ACCESS_SETUP.md ก่อนใช้งานเวอร์ชันนี้
ต้องติดตั้ง migration ใหม่ ตั้งบริการส่งอีเมล และเปิดยืนยันอีเมลก่อน deploy
หน้าแชทเปิดได้เฉพาะบัญชีที่ยืนยันอีเมลโรงเรียนสำเร็จ
หลังบ้านอยู่ที่ admin.html และมี vercel.admin.json สำหรับ deploy แยกเว็บ
คำแนะนำเวอร์ชันออกแบบเดิมด้านล่างเป็นประวัติ ไม่ใช่ขั้นตอนติดตั้งระบบยืนยันอีเมล

เวอร์ชันออกแบบใหม่ สีเขียวหลัก (6 ตุลาคม 2026)

1. ติดตั้ง Node.js 22 ขึ้นไป
2. เปิดโฟลเดอร์นี้ แล้วรัน npm ci
3. คัดลอก .env.example เป็น .env.local
4. ใส่ VITE_SUPABASE_URL และ VITE_SUPABASE_ANON_KEY ของ Supabase เดิม
5. รัน npm run dev เพื่อดูเว็บ หรือ npm run build เพื่อ deploy

ไม่ต้องเปลี่ยนฐานข้อมูลสำหรับการออกแบบใหม่นี้
ระบบ login, เพื่อน, realtime, รูปภาพ และลบโพสต์ 2 ชั่วโมงใช้ระบบเดิม
ชื่อ mnchat ภายใน SQL/Edge Function คงไว้เพื่อให้ข้อมูลและบัญชีเดิมทำงาน

ไฟล์ ZIP นี้เป็นซอร์สโค้ด ไม่มีรหัสลับหรือ node_modules
เว็บ production ยังเป็นเวอร์ชันเดิมจนกว่าจะ deploy ไฟล์ใหม่
อ่าน README.md และ MIGRATION_NOTES.md สำหรับรายละเอียด
